# Security

Do not post credentials, cookies, private URLs or raw private captures in public issues. Use GitHub private vulnerability reporting for this repository when available; otherwise contact the repository owner through their GitHub profile before sharing sensitive details.

Treat task URLs and external input files as untrusted. The input tools verify local files and perform no website requests. Run retrieval systems with appropriate isolation and account limits. A matching hash establishes identity, not safety or permission to redistribute a file.
